# Weather API

An application that uses a weather API by OpenWeatherMap

## What It Does

- Retrieves JSON data to include:
	- Weather in city selected, temperature, condition, and humidity
Features:
	- API integration
	- API key authentication
	- Error handling
	- JSON response processing

## Setup

```bash
pip install -r requirements.txt
```

## Usage

```python
weather.py

```

## Sample Output

```
API key is invalid or not yet active. Check your .env file.

```

## Stack

Python, requests, os, dotenv (load_dotenv)

## Configuration

Create a .env file, add API key, and include .env file in the .gitignore file
